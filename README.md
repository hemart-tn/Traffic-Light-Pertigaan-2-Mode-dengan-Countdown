# 🚦 Traffic Light Pertigaan 2 Mode dengan Countdown

Sistem lampu lalu lintas otomatis berbasis Arduino untuk pertigaan, dilengkapi display countdown 7-segment dan 2 mode operasi.

---

## ⚙️ Fitur
- 🚦 3 Jalur (A, B, C)  
- ⏱️ Countdown real-time  
- 🌙 Mode malam (lampu kuning berkedip)  
- 🔄 Sistem berbasis FSM  

---

## 🚀 Cara Kerja
Sistem bekerja dengan siklus:
- 🔴 Merah (26 detik)  
- 🟡 Kuning (3 detik)  
- 🟢 Hijau (10 detik)  

Setiap jalur bergantian aktif dengan countdown yang tampil pada 7-segment.

---

## 🌙 Mode Operasi

### Mode Normal
- Sistem berjalan sesuai siklus waktu
- Countdown aktif di setiap jalur
- Digunakan saat kondisi lalu lintas normal

### Mode Malam / Sepi
- Semua lampu → 🟡 kuning berkedip
- Tidak ada sistem antrian
- Digunakan saat lalu lintas sepi
